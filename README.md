# GreyRadar

Personal Intelligence Dashboard for macOS.

## Overview

GreyRadar is a private, non-commercial native macOS application designed to aggregate relevant news, software updates, product announcements, and community discussions from multiple information sources.

## Planned features

- Native SwiftUI interface
- RSS and Atom feed integration
- GitHub release monitoring
- Custom information sources
- Topic-based filtering
- Duplicate detection
- Local data storage
- Daily personalized digests
- macOS menu bar integration
- Source availability diagnostics

## Reddit integration

Reddit integration is currently pending authorization.

The proposed integration is strictly read-only, intended for a single personal user, and limited to 18 predefined public subreddits.

No Reddit API access will be implemented or enabled until an officially supported access method has been approved.

No Reddit content will be used for AI model training, commercial purposes, or public redistribution.

## Privacy

GreyRadar is designed around local-first data processing, minimal data collection, secure credential storage, and compliance with the terms of each information provider.
